Generated by `scripts/validation_report.py`. Every expected value below is
either a closed form derived independently of the implementation or a
value NASA published. No expectation in this report was produced by
running this code.

values NASA CARA published: 53 real operational conjunctions, the Alfano
(2009) benchmark cases, and CARA's Omitron unit-test cases. Those files
are vendored unmodified under `fixtures/cara/` with provenance and

## 4. Independent numerical oracle

`tests/test_tier2_integration.py` cross-checks the engine's quadrature
against `scipy.integrate.dblquad` operating in Cartesian coordinates -
a different algorithm over a different parameterisation. Agreement is
asserted at `rtol=1e-8` across isotropic, strongly anisotropic, and
rotated-covariance cases.

## 6. The applicability gate against CARA's own verdicts

Sentinel refuses to return a 2D Pc when (a) relative speed is below
100 m/s, or (b) the sagitta of either object's 1-sigma along-track arc,
`sigma_T^2 / (2|r|)`, exceeds 0.1 of the smallest 1-sigma axis in the
encounter plane. Along-track uncertainty lies along the curved orbit, not
along its tangent; when that bend is comparable to the encounter plane's
tightest dimension, a flat Gaussian no longer describes where the object
can be.

| | CARA: 2D invalid | CARA: 2D valid |
|---|---|---|
| **Sentinel refuses** | 29 | 5 |
| **Sentinel returns Pc** | **0** | 19 |

The dangerous cell is the bottom-left one: a 2D Pc returned for an event
CARA says 2D cannot handle. It is **0**.

What those refusals prevent: on the 25 flagged events above 100 m/s,
which only the curvature test catches, CARA's 3D Nc differs from the 2D Pc
by factors of 0.016x to 60,722x - in both directions. On the
4 slow events, the 2D Pc understates the 3D Nc by
19 to 162 orders of magnitude.

The 5 false positives are refusals where CARA would have computed; each
is conservative (Sentinel withholds a number, it never states a wrong one):

| primary | secondary | curvilinear ratio | CARA Pc2D | CARA Nc3D |
|---|---|---|---|---|
| WORLDVIEW 1 | LEMUR 2 LILLYJO | 0.17 | 6.582e-03 | 6.587e-03 |
| GRACE-FO 2 | SPACEBEE-24 | 0.21 | 1.294e-04 | 1.295e-04 |
| TERRA | SL-16 DEB | 1.31 | 1.082e-04 | 1.081e-04 |
| AQUA | WORLDVIEW 2 DEB | 7.55 | 2.556e-04 | 2.549e-04 |
| WORLDVIEW 1 | COSMOS 2251 DEB | 57.55 | 1.763e-04 | 1.773e-04 |

**Calibration disclosure.** The 0.1 threshold was chosen on this same set of
53 events, so the table above is in-sample agreement, not a held-out test.
The nearest CARA-flagged event sits at a ratio of 0.17 (1.7x margin). The
metric is a screening heuristic motivated by orbit geometry, not CARA's
usage-violation algorithm, which propagates equinoctial covariances along
curvilinear trajectories. Porting that algorithm, and the 3D Nc method it
hands off to, is the documented next step (risk-engine-design.md s8).

## 8. Omitron cases and two documented divergences

- **Omitron Case 1** (CARA `PcCircle`, high-accuracy mode): Sentinel 2.706023527356e-05 vs CARA 2.706023476570e-05, relative error 1.9e-08.
- **Omitron Case 2**: Sentinel 1.8076611254e-01 vs CARA 1.8073630585e-01 (1.6e-04). The difference is fully explained by convention: CARA's unadjusted methods use |r|, including a 0.47 m component along the relative velocity, as the in-plane miss distance. Evaluating Sentinel's encounter plane with CARA's convention reproduces CARA's value to 1e-14 (asserted in Tier 3). Sentinel's convention matches CARA's TCA-adjusted Pc2D (section 5).
- **Omitron Test07, non-positive-definite covariance**: CARA repairs the covariance and reports Pc = 0. Sentinel returns `REFUSED` / `INVALID_COVARIANCE`. A repaired covariance is not the one the originator supplied, and a Pc of zero is a strong claim to make on its behalf.
- **Omitron Test08, 2D/3D disagreement**: forced 2D Pc 2.2661e-20 (CARA 2.2661e-20, rel. error 2.9e-06); CARA's 3D Nc is 1.9271e-05, about 15 orders of magnitude higher. Sentinel's default: `LOW_RELATIVE_VELOCITY`.
